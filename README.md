# Task 1: Exploratory Data Analysis (EDA) on Superstore Retail Sales

## Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on the Superstore Retail Sales dataset as part of the **Datheon Data Analytics Internship**. The objective is to clean raw transactional records, handle missing values, evaluate sales and profit distributions across product categories, regions, and customer segments, and analyze how discount rates impact profitability.
